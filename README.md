## ⚡ Things I'm experimenting with

### `vibe-prompt-mcp`

An MCP server for improving coding prompts before they reach an AI coding agent.

Built around a simple idea:

**Better instructions → better agent behaviour → better software.**

Exploring MCP, AI coding workflows and how much of prompt quality can be systematically improved.

---

### `vibe-coder-antigravity-starter`

A starter environment for building with AI coding agents.

It brings together skills, rules, hooks and validation patterns to make agent-assisted development more structured and repeatable.

---

### `claude-skills`

A collection of experiments around reusable skills and workflows for Claude-based agents.
